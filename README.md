# CineFlow Prep

Однофайловое веб-приложение для подготовки кинооператора к съёмкам.

## Возможности

- Сцены с экспликациями
- Раскадровка со скетчами
- Галерея референсов с тегами
- Интерактивная доска (whiteboard)
- Схемы света с графическим редактором
- Таблица смен (КПП) с импортом из Excel
- Документы и состав съёмочной группы
- Командный чат с уведомлениями

## Стек

- React 18 (UMD production) + Babel Standalone — без сборки, весь код в одном `index.html`
- Tailwind CSS (CDN, кастомная палитра)
- Firebase (анонимная авторизация + Firestore) — синхронизация в реальном времени
- SheetJS (xlsx) — импорт КПП из Excel
- Gemini API — ИИ-функции (ключ вводится пользователем в меню «Проект»)

## Запуск

Приложение не требует сборки — достаточно открыть `index.html` в браузере
или разместить его на любом статическом хостинге.

## Деплой

Netlify Drop: перетащить `index.html` на [app.netlify.com/drop](https://app.netlify.com/drop).
Обновление — перетащить новый файл в Deploys той же площадки.

Подробности архитектуры и известные ограничения — в [CLAUDE.md](CLAUDE.md).
