# CineFlow Prep — техзадание на редизайн для Claude Code

Самодостаточный документ. Ничего прикладывать не нужно.

**Проект:** `afalin8-ui/cineflow`, ветка `master`, один файл `index.html` (~190 КБ): React 18 UMD + Babel standalone inline, Tailwind через CDN, Firebase compat (Firestore + Auth), SheetJS для импорта XLSX, service worker.

**Задача:** переработать оформление и структуру интерфейса. Логику, работу с Firestore, синхронизацию, обработчики и данные не менять. Это редизайн, не рефакторинг.

---

## Как работать

Экран за экраном, в порядке из раздела 3. После каждого шага останавливайся и показывай результат — приложение должно оставаться рабочим на каждом шаге.

Приложение стартует с модалки «Профиль Оператора». Чтобы её пропустить при проверке, положи в localStorage `cf_user_name` и `cf_user_role`.

Разделы переключаются состоянием `currentView`, значения: `notion` (Сцены), `gallery` (Галерея референсов), `master` (Мастер-документ), `whiteboard` (Доска), `table` (КПП/Смены), `docs` (Экспликации). Каждый — блок `<div className={h-full w-full ${currentView === '…' ? 'block' : 'hidden'}}>`.

Сущности в состоянии: `scenes`, `storyboard` (кадры, поле `sceneId`), `references` (поле `sceneId`, `tags`), `stickies`, `lightSchemes`, `gearTypes`, `lightGearTypes`, `crew`, `messages`, `docs`, `projectFiles`. Записи идут через `syncDoc(collection, id, data)`.

## 1. Принципы

Три вещи, из которых складывается ощущение. Если правка им противоречит — правка неверна.

**Управление занимает мало места.** Навигация — вертикальный рельс 66 px слева. Шапка 42 px и в ней только то, что не навигация. Всё остальное место — контент. Боковые панели сворачиваются в полоску 40 px.

**Фон никогда не светлее контента.** Пять поверхностей по яркости: `--canvas` < `--bg` < `--panel-3` < `--panel-2` < `--panel` < изображения. Фотографии и превью кадров — самое светлое пятно на экране. Если блок «пропадает» — поднимай блок на `--panel`, а не осветляй фон.

**Сетки на `auto-fill`.** `repeat(auto-fill, minmax(Npx, 1fr))` вместо фиксированного числа колонок: на широком мониторе больше кадров в ряд, а не две растянутые колонки.

Светлую тему не делать — на этом интерфейсе проверено, не работает.

Типографика — три семейства, больше не заводить:

```

--font-display: 'Lora'             600 — заголовки
```

Заменить Inter на Archivo в трёх местах: `tailwind.config.fontFamily.sans`, ссылка на Google Fonts (`family=Inter:…` → `family=Archivo:…`), `body { font-family }`.

## 3. Порядок работ

### Шаг 1 — токены и глобальные замены

Кроме раздела 2, сделать по всему файлу:

- `.glass-panel` — убрать `box-shadow`. В этом дизайне ничего не парит, структуру держат границы.
- Скроллбар: был синеватый `#2c353e` / `#3d4954` — не из палитры. На `var(--border)` / `#3d3a36`, толщина 6 → 8 px.
- `.glass-input::placeholder`: `#5c6a75` → `var(--muted-2)`.
- Радиусы: `rounded-xl` (12 px) → `rounded-lg` (8 px) везде, ~105 мест.
- Акцентные кнопки: `bg-indigo-600 hover:bg-indigo-500 text-white` → `bg-indigo-500 hover:bg-indigo-400 text-[#1a1918]`, ~24 места. В конфиге Tailwind `indigo-500` = `#d97757`; тёмный текст на оранжевом читается заметно лучше белого.

### Шаг 4 — Сцены (`notion`), главный экран

Три колонки: `{список 272px|40px} minmax(0,1fr) {панель кадра 330px, опционально}`.

**Список сцен** (`--panel-3`): поиск-инпут (`--bg`, рамка `--border`, `padding: 8px 10px`), затем строки на `.cf-row`. Строка = превью 54×40 + четыре линии:

1. код сцены (моно 12, у активной `--accent`) и дата справа (моно 10, `--muted-2`);
2. описание 12.5, `text-overflow: ellipsis`;
3. слаглайн моно 10 `--muted-2`, обрезается;
4. счётчики моно 10 `--muted`: «4 кадра · 8 реф · 3 света» — считать из `storyboard`, `references`, `lightGear`.

Внизу «Готовность · N из M сцен».

**Центр.** Шапка сцены: строка `СЦ {number}` (моно 13, `--accent`) + слаглайн (моно 11, `--muted-2`, обрезается) + дата справа; заголовок Lora 25; экспликация (`content`) 13.5/1.6 цветом `--text-2`, `max-width: 660px`, `text-wrap: pretty`.

Ниже панель раскадровки: `.cf-eyebrow` «РАСКАДРОВКА · SHOT LIST», справа переключатель кадры/текст, «+ кадр», текстовая кнопка «скрыть панель кадра →».

Переключатель: контейнер `padding: 2px`, рамка `--border`, `border-radius: 7px`; активная половина `--accent` с текстом `--bg`, неактивная прозрачная с `--muted`; сегменты 11 px, `padding: 4px 9px`. Состояние общее с мастер-документом — один `shotMode` на приложение.

**Режим «кадры»**: `repeat(auto-fill, minmax(248px, 1fr))`, `gap: 10px`. Карточка: `padding: 8px`, `border-radius: 10px`, у активной фон `--panel`; превью высотой 158 px, рамка активного `--accent`, иначе `--border`; на превью две метки `.cf-overlay` — слева сверху тип («скетч» / «фото»), слева снизу «план · движение»; под превью код кадра (моно 11.5) и оптика справа (моно 10.5, `--muted-2`), затем описание 12.5/1.4 цветом `--text-2`. Последняя ячейка — пунктирный `+ кадр или скетч`.

**Режим «текст»**: таблица в рамке `--border-soft`, `border-radius: 10px`. Сетка строго `76px 76px minmax(160px,1fr)` — одинаковая в шапке и в строках. Не `auto`: каждая строка считает `auto` заново, и колонки разъезжаются относительно шапки. Колонки: код кадра, оптика (`white-space: nowrap`), описание с приглушённым хвостом `· план · движение`.

**Панель кадра** справа (`--panel-2`), блоки через разделитель `1px var(--border)` с отступом 18 px по бокам:

- шапка: код кадра моно 10 uppercase, описание 14.5, строка параметров моно 10.5;
- Референсы — сетка 2 колонки, превью 74 px + подпись; ниже параметры на `.cf-chip`;
- Техника сцены и Свет сцены — строки «название / ×N», счётчик цветом `--accent` (из `gear`, `lightGear`, названия из `gearTypes`, `lightGearTypes`);
- Схема света — превью 124 px на `--canvas`: внутренняя рамка `rgba(240,238,230,.22)`, точка камеры 22×22 `--accent` с буквой, приборы 12×12 `--ink-yellow`, пунктирная линия взгляда из `--accent`, подпись схемы моно 9.5 в углу.

### Шаг 8 — КПП / Смены (`table`)

Не плоская таблица, а карточки по сменам — так видно, где подготовка не готова.

Карточка смены: рамка `--border`, `border-radius: 10px`, фон `--panel-2`. Шапка карточки на `--panel`: «СМЕНА N» (моно 12, `--accent`), дата 13, сводка моно 11 (`--muted-2`), справа статус в рамке — нейтральный (`--muted` / `--border`) при готовности, акцентный (`--accent` / `--accent-line`), если чего-то нет: «нет схемы на 25», «нет референсов». Строки сцен: сетка `64px 300px minmax(0,1fr) 120px 96px` — код, слаглайн (моно 10.5, обрезается), описание, «2 поз · 3 света», метраж справа.

Сверху экрана заголовок Lora 20, подпись «Вспомогательный модуль: импорт XLSX от 2-го режиссёра · обновлён …» и кнопки «Импорт XLSX», «Свод техники».

### Шаг 9 — Чат группы

Правая панель 336 px поверх любого экрана, `--panel-2`, открывается пунктом «Чат» в рельсе.

Сообщение: аватар 26×26 `border-radius: 7px` (своё `--accent`, чужое `#3d3a36`), имя 12/500, роль моно 9.5, время моно 9.5 справа, пузырь 12.5/1.5 цветом `--text-2` — свой на `--accent-soft` с рамкой `rgba(217,119,87,.35)`, чужой на `--panel` с рамкой `--border`. Вложение-референс: превью 44×30 + имя файла в контейнере `--panel`. Внизу инпут и кнопка отправки 36×36 (`--accent`, текст `--bg`).

### Шаг 10 — модалки

`WelcomeModal`, `ConfirmModal`, `DrawingModal`, `Lightbox`, `ShareModal`, `ProjectModal`, `AgentModal`: фон `--panel-2`, рамка `--border`, радиус 8 px, без тени. Заголовки Lora, основная кнопка `--accent` с текстом `--bg`, вторая — `--panel` с рамкой `--border`. Убрать `backdrop-blur` там, где он не нужен: подложка `rgba(0,0,0,.8)` достаточна.

## 4. Чего не делать

- Не осветлять фон. Контент всегда светлее подложки.
- Не заводить новые акцентные цвета. `--ink-yellow` и `--ink-blue` — только приборы на схемах, стикеры, вложения.
- Не возвращать управление в шапку. Всё, что не контент, живёт в рельсе, в панели раздела или сворачивается.
- Не задавать `auto`-треки в табличных сетках, где шапка и строки — отдельные гриды.
- Не растягивать сетки фиксированным числом колонок.
- Не делать светлую тему.
- Не менять логику Firestore, `syncDoc`, обработчики рисования и пан/зум.
- Не опускать тач-таргеты ниже 44 px — приложением пользуются с планшета на площадке.

## 5. Чеклист приёмки

- [ ] Шапка ≤ 42 px, в ней нет табов
- [ ] Навигация в рельсе 66 px, на телефоне — лента с таргетами 44 px
- [ ] Ни одного `box-shadow` на панелях
- [ ] Ни одного цвета вне токенов (проверить поиском `#` в стилях и классах `bg-[#…]`)
- [ ] Inter нигде не осталось
- [ ] Радиусы 8 px, `rounded-xl` не встречается
- [ ] Список сцен, теги и оглавление сворачиваются
- [ ] Раскадровка и галерея на `auto-fill`
- [ ] Переключатель кадры/текст работает в обоих местах от одного состояния
- [ ] Мастер-документ — один свиток со всеми сценами
- [ ] КПП карточками по сменам, статус готовности виден
- [ ] Фокус акцентный, браузерного синего ринга нет
- [ ] Приложение проходит: профиль → сцены → кадр → референс → доска → документ → КПП, ничего не падает
