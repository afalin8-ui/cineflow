# Текстуры поверхности

Здесь лежат фотосканы грунта, которые натягиваются на ландшафт
в наземном бою. Игра смешивает их **по уклону** прямо в шейдере:
на пологом — трава, на обрыве — камень, между ними — глина.
В больших движках этот приём зовётся splatting, и именно он даёт
поверхности характер, которого не бывает у процедурного шума.

| Файл | Что это | Источник |

| `rock_diff.jpg` / `rock_nor.jpg` | скальная стенка | Poly Haven, `rock_face_03` |
| `dirt_diff.jpg` / `dirt_nor.jpg` | глина с щебнем | Poly Haven, `brown_mud_rocks_01` |

**Лицензия — CC0** (общественное достояние). Указывать авторство не
требуется, использовать можно как угодно, в том числе в публичном
репозитории. https://polyhaven.com/

Скачано в 1K и ужато до 512 с качеством 0.82: текстура повторяется
на карте десятки раз, поэтому разрешение выше не читается, а вес
падает с 5,8 МБ до 460 КБ. Для планшета это решающая разница.

## Наборы по биомам

Слоёв всегда три — «пологое», «среднее», «обрыв», — а раскладка своя
у каждого биома (`TERRAIN_SETS` в `textures.js`):

| Биом | пологое | среднее | обрыв |
|---|---|---|---|
| `green` | трава | глина | скала |
| `klotho`, `desert` | песок | глина | скала |
| `ice` | снег | камень | скала |
| `rock` | камень | глина | скала |
| `city` | глина | камень | скала |

Новый биом стоит одной строки в таблице, а не нового комплекта
текстур. Снег и песок — с ambientCG (`Snow010A`, `Ground054`),
скала — `Rock030`, тоже CC0.

Обшивка кораблей — `hull_diff/nor` (ambientCG `Metal032`): один скан
металла на все детали корпуса. Плоский цвет — главная причина, по
которой корабль из примитивов читается макетом.

## Как заменить своими

Положи рядом файл с тем же именем — и всё. Требования:

- **бесшовная** (tileable) текстура, иначе будет видна сетка стыков;
- квадратная, 512 или 1024;
- к карте цвета желательна карта нормалей `*_nor.jpg` в формате
  OpenGL (зелёный канал направлен вверх). Poly Haven отдаёт такие
  под именем `nor_gl`;
- JPEG. PNG весит вчетверо больше без видимой пользы.

Где брать ещё, всё CC0 и без регистрации:

- **polyhaven.com/textures** — сканы, есть API, качество лучшее
- **ambientcg.com** — огромная библиотека, тоже CC0
- **kenney.nl** — стилизованные наборы, если захочется уйти
  от фотореализма в сторону мультяшности

Масштаб повтора задаётся в `ground.js` (`uTexScale`), у каждого слоя
свой множитель — одинаковый выдаёт повтор регулярной сеткой.
