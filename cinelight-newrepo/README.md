# CineLight

Пульт управления светом по DMX. Одна страница, открывается в браузере,
работает пальцем на планшете. Три экрана: **Пульт**, **План**, **Патч**.

Сделан для съёмочной площадки: без трекинга, без модального синтаксиса,
без бесконечных меню — то, что видно на экране, то и записывается в сцену.

---

## Что в папке

| Файл | Что это |
|---|---|
| `cinelight.html` | Сам пульт. Один файл — можно просто открыть в браузере |
| `cinelight-bridge.js` | Мост: превращает то, что делает пульт, в сетевые пакеты Art-Net / sACN для ноды |
| `cinelight-bridge.bat` | Запуск моста на Windows двойным щелчком |
| `app/` | Проект приложения для iPad (работает без компьютера и без моста) |
| `tools-build-fixture-library.js` | Пересборка библиотеки приборов из Open Fixture Library |
| `.github/workflows/ios.yml` | Сборка iPad-приложения на серверах GitHub |

## Как запустить на площадке (Windows + нода по Wi-Fi)

1. Поставить [Node.js](https://nodejs.org) — один раз, обычной установкой.
2. Положить `cinelight.html`, `cinelight-bridge.js` и `cinelight-bridge.bat`
   в одну папку.
3. **Пока есть интернет** — запустить `cinelight-bridge.bat` один раз.
   Он скачает всё, что нужно пульту, в папку `cinelight-vendor/`.
   Дальше интернет не понадобится никогда.
4. На площадке подключить компьютер к сети ноды (её точке доступа),
   запустить `cinelight-bridge.bat` и открыть адрес, который он покажет —
   например `http://192.168.1.5:9070`.
5. С iPad открыть **тот же адрес** — планшет должен быть в той же сети.
   Кнопка «Поделиться» → «На экран "Домой"» сделает из него приложение.

Если Windows спросит про доступ в сеть — разрешить для частных сетей.
Если iPad не открывает страницу, чаще всего виноваты две вещи: планшет
в другой сети (мобильный интернет вместо Wi-Fi ноды) или брандмауэр.
Мост при запуске печатает команду для брандмауэра — её можно скопировать.

## Без ноды, через USB-интерфейс

Интерфейсы с протоколом Enttec DMX USB Pro подключаются прямо из браузера
(Chrome или Edge на Windows и Mac), мост не нужен. Кнопка «USB» в настройках.

## Без компьютера вообще

Папка `app/` — проект приложения для iPad. Внутри приложения iPad шлёт
Art-Net в ноду сам. Что для этого нужно — написано в `app/README.md`.

## Работа вдвоём

Оператор и пультовик открывают пульт с одного и того же адреса моста.
Мост пересылает состояние между ними: сцены, программер, эффекты, мастер.
Главного нет — кто последним тронул ручку, тот на полторы секунды и главный.
Выбор приборов у каждого свой, чтобы не мешать друг другу.

Свет в кабель отдаёт только один пульт (галочка «Выход DMX» в настройках);
если её включат оба, один автоматически уступает.

## Хранение проекта

Проект лежит в самом браузере (localStorage). Экспорт и импорт JSON —
в настройках. Никаких облаков и учётных записей.

## Правила разработки

- Пульт — **один файл без сборщиков**. Никаких npm-пакетов и webpack:
  файл должно быть можно просто перетащить на Netlify Drop или открыть с флешки.
- Файл большой — править точечно, не переписывать целиком.
- После правок проверять парность скобок: Babel в браузере на синтаксической
  ошибке молча показывает белый экран.
- `cinelight-bridge.bat` обязан оставаться в CRLF и CP866 — иначе cmd.exe
  его не выполнит. Это закреплено в `.gitattributes` (`*.bat -text`).
  Правите bat — пишите байты скриптом, а не обычным редактором.

Подробности архитектуры — в `CLAUDE.md`.
