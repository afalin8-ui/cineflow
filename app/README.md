# CineLight на iPad — приложение без компьютера

Обычный пульт (`cinelight.html`) — это страница в браузере, и браузеру Apple
не разрешает слать сетевые пакеты Art-Net напрямую. Поэтому в браузерном
варианте нужен мост на компьютере.

Собранное приложение это ограничение снимает: внутри него доступен настоящий
сетевой сокет, и **iPad шлёт свет прямо в ноду — ни компьютера, ни моста**.

Всё уже подготовлено. Остаётся оплатить аккаунт Apple и нажать кнопку.

---

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `package.json` | Список того, что скачивается при сборке |
| `capacitor.config.json` | Имя приложения, значок, цвет фона |
| `prepare-www.js` | Кладёт пульт и его библиотеки внутрь приложения, чтобы оно работало без интернета |
| `github-workflow-ios.yml` | Сборка на серверах GitHub — свой Mac не нужен |

Папки `www/`, `node_modules/` и `ios/` создаются при сборке и в репозиторий
не попадают.

---

## Шаг 1. Проверить, что всё собирается (бесплатно, 10 минут)

Это можно сделать хоть сейчас, до всяких оплат — просто чтобы убедиться,
что проект живой.

1. Скопируйте `app/github-workflow-ios.yml` в репозитории по пути
   `.github/workflows/ios.yml`.
2. На GitHub откройте вкладку **Actions** → «Сборка iPad-приложения» →
   кнопка **Run workflow**.
3. Через 10–15 минут в результатах появится файл сборки.

Установить его на iPad ещё нельзя — он без подписи. Но если сборка прошла,
значит дальше дело только за аккаунтом Apple.

---

## Шаг 2. Аккаунт Apple Developer

Обойти его нельзя: Apple не даёт поставить самодельное приложение на iPad
без подписи разработчика. Это **$99 в год**, оформляется на
[developer.apple.com](https://developer.apple.com/programs/).

Бесплатный вариант существует, но он плохой: приложение живёт 7 дней,
и каждый раз для переустановки нужен компьютер с Xcode — то есть ровно то,
от чего мы уходим.

---

## Шаг 3. Подписанная сборка

После оплаты нужно один раз положить в репозиторий четыре секрета
(**Settings → Secrets and variables → Actions**):

| Секрет | Где взять |
|---|---|
| `APPLE_CERT_P12` | Сертификат разработчика, выгруженный в файл .p12 и закодированный в base64 |
| `APPLE_CERT_PASSWORD` | Пароль, который вы задали при выгрузке сертификата |
| `APPLE_PROFILE` | Provisioning profile из кабинета Apple, тоже в base64 |
| `APPLE_TEAM_ID` | Номер команды, виден в кабинете Apple |

Когда дойдёте до этого шага — скажите, и я допишу в сборку подписывание
и выгрузку в TestFlight. Дальше обновления будут прилетать на iPad сами,
как у обычного приложения.

---

## Как это работает внутри

Пульт при запуске проверяет, где он открыт. Внутри приложения он находит
сетевой модуль и включает прямой выход: в настройках появляется раздел
«Выход DMX · прямо с этого устройства». В браузере этого раздела нет,
и остаётся мост — то есть один и тот же файл `cinelight.html` работает
в обоих случаях, и правки не нужно дублировать.

Сборка сама кладёт внутрь приложения все библиотеки, поэтому на площадке
интернет не нужен вообще.

---

## Собрать на своём Mac (если он есть)

```
cd app
npm install
node prepare-www.js
npx cap add ios
npx cap sync ios
npx cap open ios
```

Откроется Xcode — дальше обычная сборка на подключённый iPad.
